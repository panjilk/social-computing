# 论文工作文件

本目录保存论文写作材料，不是独立的可运行模型。当前可运行代码以项目根目录 README 和 `IMAGE_RESEARCH_MAINLINE.md` 为准。

当前模型组件包括：固定条件双渠道竞争、国内支持与客户使用对照、客户依赖扫描，以及持续争议与信息传播扩展。对应结果目录分别为 `outputs/competition_v1`、`outputs/substitution_complementarity_v1`、`outputs/dependence_gap_v1` 和 `outputs/continuous_competition_v1`。

`MANUSCRIPT_ZH.md` 是早期工作稿，保留其历史数值和讨论用于追踪写作变化；引用其中结果时必须核对对应输出目录，不能把它当作最新投稿稿。

建议阅读顺序：

1. [贡献与边界](CONTRIBUTION_BOUNDARIES.md)：哪些能写、哪些尚不能声称。
2. [中文初稿](MANUSCRIPT_ZH.md)：摘要、引言、相关研究、模型公式、实验设计、实际结果、讨论和限制。
3. [文献核查](LITERATURE_REVIEW.md)：8条文献/官方材料，注明网页/PDF访问程度和模型关联。
4. [BibTeX参考文献](references.bib)：已核查的题录，保留访问限制备注。

这不是最终投稿稿，也没有完成系统性查新。尚未取得全文的研究不可冒充精读；免费文章不等于开放代码；正文未把FLA等多方组织等同于商业客户。
